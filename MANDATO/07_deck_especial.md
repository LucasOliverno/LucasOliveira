## 7. Orçamento de poder (referência para criar novas cartas)

| Item | Valor em PU (Power Units) |
|---|---|
| 💰1 | 1,0 |
| 🔨1 | 1,2 |
| 🗳️1 | 1,5 |
| Comprar 1 carta | 1,5 |
| +1 😊 | 1,5 |
| Remover 1 🕵️ | 1,0 |
| Adicionar 1 🕵️ | −1,0 |
| ⚡/💧 +1 de capacidade | 0,8 |
| ☁️ −1 | 0,8 |
| Avançar 1 Facção | 1,5 |
| ⭐1 | ≈ 8 |
| **Renda por turno** | produção × 3 (vida útil efetiva ~6 turnos, com 50% de desconto) |

**Regra prática:** o custo total (Aq + Ob) de uma Edificação deve ficar entre **70% e 100%** do valor presente da produção. Cartas de ação devem render **valor ≈ Aq + 0–1 PU** (o prêmio por carta "extra" vem de sinergias).

Exemplo: *Mercadinho de Bairro*: produção ≈ 1,0 + 0,7 (adj.) = 1,7/turno × 3 = 5,1 PU; custo = 3 + 1,2 = 4,2 PU → **82%** ✔.
